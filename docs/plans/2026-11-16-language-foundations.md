# Python 与 C 基础课程

依据浙江大学公开课程，按本项目的逐行教学形式重新编排；不是浙大官方课程或作业复刻。

- Python：https://higher.smartedu.cn/course/62354d0b9906eace048ea9f1
- C：https://www.icourse163.org/course/ZJU-199001

Python 取基础语言部分：输入输出、数字、字符串、列表与元组、分支循环、集合字典、函数作用域、递归、异常和文本文件。省略原课的类与对象、第三方数据分析、Web 与爬虫。
C 以入门部分为界：编译运行、类型与表达式、输入输出、分支循环、数组、函数、指针和字符串；不加入动态内存、链表、函数指针与图形库。

每章独立程序，顺序学习。概念先定义；题目、怎么想到的、思路各自一页；随后按小步骤写代码，每个操作先解释动机；最后展示运行、边界情况与练习。示例自行编写，不使用 LeetCode 的类封装。

运行环境：Python 3.10+；C11 与 GCC。网页播放预先编写的代码与终端输出，不提供在线解释器。输入通过命令行重定向提供可复现的示例，读者也可在本地直接交互输入。

验证：全课程引擎逐帧校验；新课程逐章真实执行并比对输出；C 使用 -std=c11 -Wall -Wextra -Werror；本地浏览器验证首页入口、课程目录与播放器。

用户确认无需再查 AGENT.md；遵守 STYLE.md 与 PLAN.md，用户本次限定优先于旧计划中的 OOP 与链表章节。
